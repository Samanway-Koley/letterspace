Letter spacing FAQ

Figma tracking to CSS questions, answered.

Clear answers for converting Figma typography values into accurate, production-ready CSS letter spacing.

Why does Figma express letter spacing as a percentage?

Figma uses percentage values for tracking so letter spacing scales dynamically with font size changes. Because web browsers require explicit CSS units like px, em, or rem, converting percentages is essential for pixel-perfect design handoffs.

Should I use px or em for CSS letter-spacing?

Use pixels (px) for fixed UI elements like buttons and badges. Use relative units like em for responsive body copy and fluid typography, allowing letter spacing to scale proportionally alongside layout changes.

How do I convert Figma pixel letter spacing back to percentage?

Toggle to px to % mode in the converter above. This calculates the exact percentage equivalent needed for Figma design systems when updating code back into Figma.

What is the best way to handle Figma line height when writing CSS?

In Figma, line height is usually shown as a percentage or fixed pixel size. When writing CSS, unitless values (e.g., 1.5) or exact pixels (24px) are ideal to ensure proper scaling and vertical rhythm. You can use the converter above to automatically derive both unitless ratios and CSS pixel values directly from your Figma design properties.

Why is unitless line height preferred over pixel line height in CSS?

Unitless values (like line-height: 1.5) inherit proportionally to child elements without causing unexpected visual overlap or clipped text when font sizes change across mobile breakpoints.

How does line height in Figma differ from CSS line-height?

Figma calculates line height relative to the font's bounding box and displays it as percentage or pixels. CSS supports unitless multipliers, percentages, and absolute lengths, making precise conversion necessary during front-end development.

Why do large headlines in Figma need negative letter spacing?

Larger font sizes increase the optical gap between characters. Applying negative tracking in Figma (and negative letter-spacing in CSS) tightens display text for improved readability and tighter visual rhythm.

How does Figma tracking differ from CSS letter-spacing?

Figma tracking applies proportionally to the active font size using percentages. CSS letter-spacing requires unit values like px or em, requiring direct conversion to preserve the visual design intent.
